# 机械臂仿真前端

双 UR5 机械臂浏览器仿真，包含夹爪切换、桌面物体、求解器、可选物理引擎和录制导出功能。

## 本地运行

安装 Node.js 18 或更新版本，在仓库根目录执行：

```sh
npm start
```

打开 http://127.0.0.1:5175/ 。Windows 也可以双击 `start.cmd`。

前端依赖已包含在仓库中，无需执行 npm install，也无需编译。启动程序仅监听本机地址；关闭终端或按 Ctrl+C 停止服务。

如需指定其他端口：

```sh
npm start -- 5176
```

## 目录结构

```text
robotarm/
├── dist/              实际运行的前端源码与静态资源，需要提交到 Git
│   ├── index.html     页面入口
│   ├── app.js         应用入口及其他功能模块
│   ├── style.css      界面样式
│   ├── models/        机械臂、夹爪、物体和桌面资源
│   └── vendor/        本地第三方运行依赖
├── server.mjs         本地静态文件服务
├── start.cmd          Windows 启动入口
├── package.json       项目信息和启动命令
├── .gitignore         本地文件与导出结果的忽略规则
└── .gitattributes     文本换行和二进制文件规则
```

本仓库沿用 `dist/` 名称以兼容现有入口及资源路径。它是直接编辑的前端源目录，不是可删除、可重新生成的构建产物。修改页面、脚本和模型时直接编辑对应文件。

## Git 管理约定

- 提交 `dist/` 中的源码、运行依赖、模型、纹理及第三方授权说明，以及根目录的项目配置和启动文件。
- `recordings/`、`exports/`、`artifacts/`、`tmp/` 是本地输出目录，不提交录制视频、导出数组或临时产物。
- 不提交 `node_modules/`、缓存、日志和 `.env` 等个人配置或凭据。
- 第三方模型和依赖的来源、许可见各自目录的 README、LICENSE、UPSTREAM-LICENSE 和 SOURCE 文件，分发时保留这些文件。

## 基本检查

```sh
npm run check
```

该命令检查服务入口和应用入口的 JavaScript 语法；功能验证需在浏览器中运行。

## 发布

`dist/` 可作为静态网站根目录部署。当前仓库提供前端和本地服务，没有包含原项目的云端发布凭据或发布流程。模型与脚本应保持原有相对路径。
